## 连上去：三端步骤和连不上时先查什么

Windows 连 Windows 最快。按 `Win + R` 输入 `mstsc`，在“计算机”里填 IP，端口不是默认 3389 的话写成 `IP:端口`，用户名一般是 `Administrator`，密码在开通邮件或控制面板里。首次连接会弹证书提示，接受即可。

Mac 没有内置 RDP 客户端，去 App Store 装微软官方的 Microsoft Remote Desktop，新建 PC，填 IP 或 `IP:端口`、用户名、密码。iPhone、iPad 和安卓用同一款微软官方应用。

服务器端 RDP 没开的时候，从控制面板的 VNC 进系统：右键“此电脑”→“属性”→“远程设置”→勾选“允许远程连接到此计算机”，顺便勾上“仅允许运行使用网络级别身份验证的 NLA 的远程桌面连接”，再去防火墙确认 3389 端口的入站规则是放行状态。

连不上按顺序排查三件事，多数问题出在前两步：

1. IP 和端口是否填对，改过端口却仍用默认 3389 是最常见的错
2. 防火墙里 3389 的入站规则有没有放行
3. 前两步都没问题就在控制台重启一次实例，再看 VNC 里系统是否正常启动

连上了但操作发涩，先换机房，不要急着加配置。配置不够的表现是程序卡死、内存告警；延迟高的表现是画面一顿一顿但 CPU 占用不高，两者别混。

安全上有几件事顺手做了：改掉默认的 Administrator 密码，用控制面板防火墙把 3389 限制在自己常用的 IP 段，保留 NLA，别关系统更新。每周的自动异地备份能兜住更新翻车这类事故。

## 常见问题

**2 GB 内存够跑 Windows Server 吗？**
够跑系统和两三个常用程序，浏览器开十几个标签再加 Office 就会开始吃紧。只做单用户办公，VM-1 能用；要长期多开，直接上 VM-2 的 4 GB。

**512 MB 的 VM-0.5 能装 Windows 吗？**
能下单不代表能用。Windows Server 带桌面体验的官方最低内存是 2 GB，512 MB 和 1 GB 这两档装 Linux 才是合理用法。

**能不能几个人同时远程登录同一台？**
官方页面没有多用户授权和并发会话的说明，按单用户远程桌面使用。多人协作要么向商家确认授权，要么选按用户计价的方案。

**香港节点和标准节点差在哪？**
价格一样，机房位置和流量不同。香港、大阪延迟更低，月流量约为标准线路的一半；标准线路机房更多，同价位给的流量更宽。

**备份要另外买吗？**
不用。所有套餐都含每周自动异地备份，不收额外费用。

**退款怎么算？**
24 小时内全额退款。窗口很短，配置和机房在付款前定好。
